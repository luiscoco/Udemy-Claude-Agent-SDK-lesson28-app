Rule forms · reference

These cards describe documented semantics. The events below contain actual observations. Global * and absolute-path examples are reference topics; the live path experiment uses a relative anchor.

Allow entry

Pre-approves matching calls. Unlisted tools can still exist and reach the mode or callback.

Bare deny

Removes a matching tool definition before the model can request it.

Scoped deny

Keeps the tool and rejects matching commands or paths at runtime.

Wildcard deny

The mcp__* form denies matching MCP calls; this runtime still reports their names. A global * deny removes every tool definition.

MCP allow glob

Use a literal server prefix, such as mcp__classroom__read_*. A glob in the server segment is invalid.

Path rule

Edit(./protected/**) covers Write too. Use Edit(path), not Write(path), for scoped file-write rules.
