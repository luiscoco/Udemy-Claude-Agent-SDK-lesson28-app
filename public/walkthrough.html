01

Allow is pre-approval

An allow list is not the available-tool inventory and does not constrain bypass mode. Unlisted calls can reach the mode or callback. Reads in the working directory may already qualify as safe built-in approvals, so a successful read alone does not prove a particular allow entry decided it.

02

Bare, scoped and wildcard deny

Bare Write removal is verified separately. Scoped rules match commands or paths as written. The supplied slides and current docs describe wildcard denial as removal. In the pinned SDK MCP experiment, initialization still reports MCP names and actual calls receive permission denials. This lab verifies denied execution, not MCP definition removal. The global * form is reference syntax, not another live experiment.

03

MCP literal-server patterns

Valid allow forms include mcp__classroom__* and mcp__classroom__read_*. The server segment must be literal; mcp__*__read_lesson is not a valid MCP allow pattern. The live experiment uses local classroom and archive servers, not external accounts.

04

Path anchors and write coverage

The live path experiment uses Edit(./protected/**). Current SDK docs specify Edit(path) for Write and NotebookEdit too; Write(path) is not equivalent. A double slash marks an absolute path, such as Edit(//secrets/**), while one slash anchors at the rule source. These anchor examples are reference syntax, not tested filesystem targets.

05

Project source and mock .env

Only project mode enables settingSources project and writes actual .claude/settings.json. Read(./.env) protects a disposable mock file. The application’s real .env is never served or placed in the agent working directory.

06

Ask before a write

The supplied lesson suggests asking before git push. This application demonstrates the same ask-to-callback mechanism using a fixed local Write; no git push is performed or simulated. The callback is programmed classroom policy, not a human approval dialog.

07

dontAsk has qualifications

Pair pre-approved reviewer tools with dontAsk to deny calls that would prompt. Safe built-in operations may still run. Explicitly choose tools or use bare denies when removal is required. SDK permission rules alone are not an operating-system sandbox.

08

Evidence and API cost

The nine experiments use actual SDK queries with a $0.40 budget threshold per query, not a prepaid cap. Hooks, callback calls, initialization names, native feedback, MCP handlers and host file checks are observed evidence. Media, dependencies and real credentials remain excluded from Git.
